🏠 نصب روی هاست cPanelInstall on cPanel hosting

برای هاست اشتراکی با cPanel. دیتابیس را خودتان می‌سازید و نصب‌کننده‌ی تحت وب را اجرا می‌کنید. For shared hosting with cPanel. You create the database yourself and run the web installer.

Git یا ZIP ← install.php ← تست Git or ZIP → install.php → test

🖥️ نصب روی سرور (VPS)Install on a server (VPS)

برای سرور مجازی با دسترسی root. یک دستور نصب می‌کند و منوی مدیریت simorgh را می‌سازد. For a VPS with root access. One command installs everything and creates the simorgh management menu.

یک دستور ← منو ← نصب خودکار One command → menu → automatic setup
