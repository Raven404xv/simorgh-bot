نصب روی هاست cPanel Installation on cPanel hosting Установка на хостинг cPanel

1 ساخت پایگاه دادهCreate the databaseСоздание базы данных

  1. در cPanel بخش MySQL® Databases را باز کنید، یک دیتابیس و یک کاربر با رمز قوی بسازید و کاربر را با دسترسی ALL PRIVILEGES به دیتابیس اضافه کنید. In cPanel, open MySQL® Databases, create a database and a user with a strong password, then add the user with ALL PRIVILEGES. В cPanel откройте MySQL® Databases, создайте базу данных и пользователя с надёжным паролем, затем добавьте пользователя с правами ALL PRIVILEGES.
  2. نام کامل دیتابیس و کاربر را با پیشوند حساب یادداشت کنید، مثلاً cpuser_SimorghBot. Note the full database and user names, including the account prefix, for example cpuser_SimorghBot. Запишите полные имена базы данных и пользователя с префиксом аккаунта, например cpuser_SimorghBot.

2 ساخت ربات و توکنCreate the bot and tokenСоздание бота и токена

  1. در تلگرام به @BotFather بروید و دستور /newbot را بفرستید؛ توکن را کپی کنید. In Telegram, open @BotFather, send /newbot and copy the token. В Telegram откройте @BotFather, отправьте /newbot и скопируйте токен.
  2. شناسه‌ی عددی خود را از @userinfobot بگیرید. Get your numeric ID from @userinfobot. Получите свой числовой ID в @userinfobot.

6 امنیت بعد از نصبSecurity after installationБезопасность после установки

  • فایل‌های install.php و selftest.php را حذف کنید. Delete install.php and selftest.php. Удалите install.php и selftest.php.
  • فایل config.php را هرگز برای کسی نفرستید؛ شامل توکن و رمز دیتابیس است. Never share config.php; it contains your token and database password. Никогда не передавайте config.php: в нём токен и пароль базы данных.
اگر install.php باقی بماند، هر کسی که آدرس آن را داشته باشد می‌تواند تنظیمات را تغییر دهد. If install.php stays on the server, anyone with the address can change the settings. Если install.php останется на сервере, любой, кто знает адрес, сможет изменить настройки.

With ZIP: replace the src/ folder and the new *.php files; do not touch config.php or installed.lock. С ZIP: замените папку src/ и новые файлы *.php; не трогайте config.php и installed.lock.

حذف ربات از سرور Removing the bot from the server Удаление бота с сервера

دستور simorgh را اجرا و گزینه‌ی 2 را بزنید. با y ربات، تنظیمات وب‌سرور، گواهی و دیتابیس ساخته‌شده توسط نصب‌کننده حذف می‌شوند؛ با n به منو برمی‌گردید. نرم‌افزارهای عمومی مثل Apache و PHP حذف نمی‌شوند. Run simorgh and choose 2. With y, the bot, its web server settings, its certificate and the database created by the installer are removed. With n, you return to the menu. Common software such as Apache and PHP is kept. Запустите simorgh и выберите 2. При ответе y будут удалены бот, настройки веб-сервера, сертификат и база данных, созданная установщиком; при n вы вернётесь в меню. Общее ПО, например Apache и PHP, сохраняется.

5 امنیت روی سرورServer securityБезопасность сервера

  • بعد از تأیید ربات، فایل‌های install.php و selftest.php را حذف کنید. After you confirm the bot works, delete install.php and selftest.php. Когда убедитесь, что бот работает, удалите install.php и selftest.php.
  • فایل /root/simorgh-credentials.txt را پس از یادداشت‌برداری جابه‌جا یا حذف کنید. Move or delete /root/simorgh-credentials.txt after you have saved the details. После сохранения данных переместите или удалите /root/simorgh-credentials.txt.
  • اگر توکن لو رفت، در BotFather با /revoke آن را عوض کنید و گزینه‌ی 5 را اجرا کنید. If the token leaks, revoke it in BotFather with /revoke, then run option 5. Если токен утёк, отзовите его в BotFather командой /revoke и выполните пункт 5.
  • سیستم را به‌روز نگه دارید و فقط پورت‌های لازم را باز بگذارید. Keep the system updated and open only the ports you need. Регулярно обновляйте систему и оставляйте открытыми только нужные порты.

پرسش‌های متداول Frequently asked questions Частые вопросы

آیا برای نصب دامنه لازم است؟ Is a domain required? Нужен ли домен?

خیر. بدون دامنه، ربات روی IP سرور با گواهی خودامضا نصب می‌شود. با دامنه، گواهی معتبر گرفته می‌شود و هشدار مرورگر دیده نمی‌شود. No. Without a domain the bot runs on the server IP with a self-signed certificate. With a domain, a trusted certificate is issued and no browser warning appears. Нет. Без домена бот работает на IP сервера с самоподписанным сертификатом. С доменом выдаётся доверенный сертификат, и предупреждение браузера не появляется.

آیا روی سرور باید دیتابیس را خودم بسازم؟ Do I need to create the database on a VPS? Нужно ли создавать базу данных на VPS?

خیر. نصب‌کننده‌ی سرور پایگاه داده و کاربر اختصاصی را خودکار می‌سازد. No. The server installer creates the database and a dedicated user automatically. Нет. Установщик для сервера автоматически создаёт базу данных и отдельного пользователя.

آیا برای نصب روی هاست به SSH نیاز دارم؟ Do I need SSH for cPanel hosting? Нужен ли SSH для хостинга cPanel?

خیر. نصب روی هاست فقط با cPanel و مرورگر انجام می‌شود. No. Hosting installation uses only cPanel and a browser. Нет. Установка на хостинг выполняется только через cPanel и браузер.

آیا می‌توانم ربات را کامل حذف کنم؟ Can I remove the bot completely? Можно ли полностью удалить бота?

بله. روی سرور با گزینه‌ی 2 حذف کنید. روی هاست، پوشه‌ی SimorghBot و دیتابیس آن را حذف کنید. Yes. On a server, use option 2. On cPanel hosting, delete the SimorghBot folder and its database. Да. На сервере используйте пункт 2. На хостинге удалите папку SimorghBot и её базу данных.

آیا ارسال همگانی برای همه‌ی کاربران کامل انجام می‌شود؟ Does the broadcast reach all users? Доходит ли массовая рассылка до всех пользователей?

ارسال با تأخیر کوتاه بین پیام‌ها انجام می‌شود (حدود ۲۵ پیام در ثانیه). در کاربران بسیار زیاد روی هاست اشتراکی، ممکن است زمان اجرا محدود باشد و باید صف ارسال با Cron راه‌اندازی شود. Messages are sent with a short delay between them (about 25 per second). With a very large audience on shared hosting, execution time may be limited, and a Cron-based queue should be set up. Сообщения отправляются с небольшой задержкой между ними (около 25 в секунду). При очень большой аудитории на общем хостинге время выполнения может быть ограничено, и тогда нужна очередь через Cron.
