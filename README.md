## شروع

| مورد | الزام |
|---|---|
| PHP | نسخه‌ی ۸.۰ یا جدیدتر |
| افزونه‌ها | `pdo_mysql`، `curl`، `json`، `mbstring` |
| SSL | گواهی SSL فعال برای دامنه |
| محیط | هاست اشتراکی cPanel |

نصب کامل و قدم‌به‌قدم در **[مستندات نصب](https://raven404xv.github.io/simorgh-bot/)** آمده است. مراحل اصلی این‌ها هستند:

1. ساخت دیتابیس MySQL در cPanel
2. ساخت ربات و گرفتن توکن از @BotFather
3. دریافت فایل‌ها با Git یا ZIP
4. اجرای `install.php` و تکمیل فرم
5. تست ربات و حذف فایل‌های نصب

## بروزرسانی

- **با Git:** در Git™ Version Control روی مخزن نصب‌شده **Update from Remote** را بزنید.
- **با ZIP:** پوشه‌ی `src/` و فایل‌های `*.php` جدید را جایگزین کنید. فایل‌های `config.php` و `installed.lock` را دست نزنید.

---

## امنیت

- فایل‌های `config.php`، `installed.lock` و پوشه‌ی `storage/` از دسترسی عمومی مسدود هستند.
- پوشه‌ی `src/` از مرورگر قابل دسترسی نیست.
- رسیدهای پرداخت فقط توسط مدیر دیده می‌شوند.
- اعتبار مینی‌اپ با امضای رسمی تلگرام بررسی می‌شود.
- توکن ربات و فایل `config.php` را هرگز منتشر نکنید.

## رفع اشکال

| مشکل | راه‌حل |
|---|---|
| صفحه‌ی نصب خطای ۵۰۰ می‌دهد | نسخه‌ی PHP را ۸.۰ یا جدیدتر کنید |
| اتصال به دیتابیس ناموفق است | نام کامل دیتابیس و کاربر (با پیشوند cPanel) را بررسی کنید |
| ربات به `/start` جواب نمی‌دهد | فایل `selftest.php` را باز کنید |
| دکمه‌ی مینی‌اپ نمی‌آید | آدرس باید HTTPS باشد |

جزئیات بیشتر در [بخش رفع اشکال مستندات](https://raven404xv.github.io/simorgh-bot/#troubleshoot) آمده است.
