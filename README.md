# 💎 SimorghBot (نسخه‌ی PHP برای cPanel)

ربات فروشگاه پنل تلگرام با **PHP + MySQL** که روی هاست اشتراکی cPanel اجرا می‌شود.
ربات با **Webhook** کار می‌کند، پس نیازی به فرآیند دائمی یا SSH نیست.

> ⚠️ **توجه مهم:** این نسخه روی PHP اجرا و تست نشده است (در محیط ساخت، PHP نصب نبود).
> اولین بار حتماً صفحه‌ی `selftest.php` را بررسی کنید؛ اگر خطایی دیدید، خروجی را برای اصلاح بفرستید.

---

## ✅ پیش‌نیازهای هاست
- **PHP 8.0 یا جدیدتر** (در cPanel از «Select PHP Version» انتخاب کنید)
- افزونه‌های `pdo_mysql`، `curl`، `json`، `mbstring` فعال باشند
- **SSL فعال** برای دامنه (تلگرام فقط آدرس HTTPS را می‌پذیرد)
- دسترسی به **MySQL Databases** در cPanel

## 📥 نصب از GitHub

**نصب روی هاست cPanel:**
۱. در cPanel بخش **Git™ Version Control** را باز کنید و **Create** بزنید.
۲. آدرس ریپو را وارد کنید: `https://github.com/Raven404xv/simorgh-bot.git`
۳. مسیر را `public_html/SimorghBot` بگذارید (پوشه‌ی مقصد باید خالی باشد).
۴. سپس مراحل «نصب در ۶ مرحله» را از بخش ۴ به بعد ادامه دهید.

**نصب روی سرور:**
```
git clone https://github.com/Raven404xv/simorgh-bot.git
```

**به‌روزرسانی (هر دو محیط):**
```
git pull
```
فایل‌های `config.php` و `installed.lock` در `.gitignore` هستند، پس `git pull` تنظیمات شما را تغییر نمی‌دهد.

## 🚀 نصب در ۶ مرحله

### ۱) ساخت دیتابیس در cPanel
1. **MySQL® Databases** را باز کنید.
2. یک دیتابیس بسازید (مثلاً `SimorghBot`). نام کامل آن معمولاً به شکل `cpuser_SimorghBot` است.
3. یک کاربر دیتابیس بسازید و رمز قوی انتخاب کنید.
4. کاربر را به دیتابیس اضافه کنید و گزینه‌ی **ALL PRIVILEGES** را فعال کنید.

### ۲) ساخت توکن ربات
در تلگرام به **@BotFather** بروید، با `/newbot` ربات بسازید و توکن را کپی کنید.
شناسه‌ی عددی خودتان را هم از **@userinfobot** بگیرید.

### ۳) آپلود فایل‌ها
1. فایل `SimorghBot-php.zip` را در **File Manager** به پوشه‌ی `public_html` آپلود کنید.
2. روی آن راست‌کلیک و **Extract** بزنید. باید پوشه‌ی `public_html/SimorghBot/` ایجاد شود.

### ۴) اجرای نصب‌کننده
مرورگر را باز کنید و آدرس زیر را بزنید (دامنه‌ی خودتان را جایگزین کنید):

```
https://yourdomain.com/SimorghBot/install.php
```

فرم را پر کنید: توکن، شناسه‌ی ادمین، نام فروشگاه و مشخصات دیتابیس. با زدن دکمه‌ی نصب:
- توکن با تلگرام بررسی می‌شود
- جدول‌ها ساخته می‌شوند
- فایل تنظیمات `config.php` با دسترسی خصوصی ساخته می‌شود
- آدرس Webhook در تلگرام ثبت می‌شود

### ۵) تست
1. در تلگرام به ربات بروید و `/start` بفرستید.
2. با حساب ادمین، از دکمه‌ی **⚙️ پنل مدیریت** شماره کارت، صاحب کارت و محصولات را ثبت کنید.
3. با یک حساب دیگر یک شارژ کیف پول و یک خرید تست کنید.
4. صفحه‌ی `selftest.php` (لینک آخر صفحه‌ی نصب) را باز کنید؛ همه‌ی ردیف‌ها باید ✅ باشند.

### ۶) امنیت پس از نصب
- فایل `install.php` پس از نصب قفل می‌شود، اما بهتر است آن را از File Manager حذف کنید.
- بعد از اطمینان، `selftest.php` را هم حذف کنید.
- فایل `config.php` را هرگز برای کسی نفرستید؛ شامل توکن و رمز دیتابیس است.

## 🧭 قابلیت‌ها
- 🛒 خرید پنل در ۱/۲/۳ ماهه با پرداخت از کیف پول یا کارت‌به‌کارت (با رسید)
- 💰 کیف پول با تأیید رسید توسط مدیر (فقط یک‌بار اعتبار می‌گیرد)
- 🎁 تست رایگان با سهمیه‌ی قابل تنظیم
- 👥 زیرمجموعه‌گیری با پاداش
- 🎧 تیکت پشتیبانی و سوالات متداول
- 📢 عضویت اجباری در کانال‌ها
- 📦 مدیریت محصولات، کارت پرداخت، مدیران و ارسال همگانی از پنل مدیریت
- 📱 مینی‌اپ فارسی (روشن/تاریک) با احراز هویت امضای تلگرام


## ✨ تغییرات نسخه ۳
- **چیدمان دکمه‌ها** از پنل مدیریت: حالت شیشه‌ای (زیر پیام) یا کیبورد پایین صفحه.
- **تست رایگان** از پنل مدیریت قابل فعال و غیرفعال شدن است؛ وقتی غیرفعال باشد، دکمه از ربات و مینی‌اپ حذف می‌شود.
- **رنگ دکمه‌ها** برای همه‌ی بخش‌ها، با گزینه‌ی «پیش‌فرض تلگرام».
- **مینی‌اپ بازطراحی شده**: لوگوی سیمرغ، نام فروشگاه از پنل مدیریت، آیکون‌های SVG و بدون ایموجی.
- **صفحه‌های ربات** با خط عرض ثابت نمایش داده می‌شوند تا دکمه‌ها کوچک نشوند.

## ♻️ به‌روزرسانی
1. پوشه‌ی `src/` و فایل‌های `*.php` جدید را جایگزین کنید.
2. **فایل‌های `config.php` و `installed.lock` را دست نزنید** (تنظیمات شما حفظ می‌شود).
3. اگر تغییری در دیتابیس لازم شد، جدول‌های جدید با `install_schema` ساخته می‌شوند؛ داده‌های قبلی پاک نمی‌شوند.

## ⚠️ نکته‌ی ارسال همگانی
ارسال همگانی با تأخیر کوتاه بین پیام‌ها انجام می‌شود (حدود ۲۵ پیام در ثانیه). اگر تعداد کاربران خیلی زیاد باشد و هاست زمان اجرا را محدود کند، ارسال ممکن است کامل نشود؛ در این صورت باید صف ارسال با Cron اضافه شود.
