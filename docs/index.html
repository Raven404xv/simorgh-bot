💎 راهنمای نصب سیمرغ بات

ربات فروشگاه پنل تلگرام با PHP و MySQL، روی هاست اشتراکی cPanel

نسخه‌ی ۳.۳.۰

قبل از شروع: توکن ربات را فقط در صفحه‌ی نصب وارد کنید و هرگز آن را در گروه، کانال یا پیام عمومی نفرستید. اگر توکن لو رفت، با دستور /revoke در @BotFather آن را عوض کنید.

۱. پیش‌نیازها

  • هاست cPanel با PHP 8.0 یا جدیدتر (از بخش Select PHP Version انتخاب کنید).
  • افزونه‌های pdo_mysql، curl، json و mbstring فعال باشند.
  • گواهی SSL فعال برای دامنه. تلگرام فقط آدرس HTTPS را می‌پذیرد.
  • دسترسی به MySQL Databases در cPanel.

۲. نصب قدم‌به‌قدم

۱ ساخت دیتابیس

  1. در cPanel بخش MySQL® Databases را باز کنید.
  2. یک دیتابیس بسازید، مثلاً SimorghBot. نام کامل آن با پیشوند حساب ساخته می‌شود، مثل cpuser_SimorghBot. نام کامل را یادداشت کنید.
  3. یک کاربر با رمز قوی بسازید و نام کامل آن را یادداشت کنید.
  4. کاربر را به دیتابیس اضافه کنید و گزینه‌ی ALL PRIVILEGES را انتخاب کنید.

۲ ساخت ربات و توکن

  1. در تلگرام به @BotFather بروید و دستور /newbot را بفرستید.
  2. توکنی را که می‌گیرید کپی کنید. شکل آن مانند 123456:ABC... است.
  3. شناسه‌ی عددی خودتان را از @userinfobot بگیرید.

۳ دریافت فایل‌های ربات

روش الف (Git): در cPanel بخش Git™ Version Control را باز کنید، روی Create بزنید و این آدرس را وارد کنید:

https://github.com/Raven404xv/simorgh-bot.git

مسیر را public_html/SimorghBot بگذارید. پوشه‌ی مقصد باید خالی باشد.

روش ب (ZIP): در صفحه‌ی مخزن GitHub روی Code و سپس Download ZIP بزنید. فایل را در File Manager داخل public_html آپلود و Extract کنید، و نام پوشه را به SimorghBot تغییر دهید.

۴ اجرای نصب‌کننده

آدرس زیر را در مرورگر باز کنید و دامنه‌ی خودتان را جایگزین کنید:

https://yourdomain.com/SimorghBot/install.php
فیلدمقدار
توکن رباتتوکنی که از BotFather گرفتید
شناسه‌ی ادمینشناسه‌ی عددی شما
نام فروشگاهنامی که کاربران می‌بینند
میزبان دیتابیسlocalhost
نام دیتابیسنام کامل با پیشوند cPanel
نام کاربر و رمزهمان کاربر و رمزی که ساختید

بعد از زدن دکمه‌ی نصب، جدول‌های دیتابیس، فایل تنظیمات و آدرس Webhook خودکار ساخته می‌شوند.

۵ تست ربات

  1. در تلگرام به ربات بروید و /start بفرستید.
  2. با حساب ادمین، شماره‌ی کارت و محصولات را از پنل مدیریت ثبت کنید.
  3. صفحه‌ی بررسی را باز کنید:
https://yourdomain.com/SimorghBot/selftest.php

همه‌ی ردیف‌ها باید ✅ باشند.

۶ امنیت بعد از نصب

فایل‌های install.php و selftest.php را از File Manager حذف کنید. فایل config.php شامل توکن و رمز دیتابیس است؛ آن را هرگز برای کسی نفرستید.

۳. به‌روزرسانی

  • با Git: در Git™ Version Control روی مخزن نصب‌شده Update from Remote را بزنید.
  • با ZIP: پوشه‌ی src/ و فایل‌های *.php جدید را جایگزین کنید. فایل‌های config.php و installed.lock را تغییر ندهید.

۴. عیب‌یابی

مشکلراه‌حل
صفحه‌ی نصب خطای ۵۰۰ می‌دهدنسخه‌ی PHP را ۸.۰ یا جدیدتر کنید و pdo_mysql را فعال کنید.
اتصال به دیتابیس برقرار نمی‌شودنام کامل دیتابیس، کاربر و رمز را بررسی کنید.
ربات به /start جواب نمی‌دهدصفحه‌ی selftest.php را باز کنید و ردیف «خطای آخر Webhook» را بخوانید.
دکمه‌ی مینی‌اپ نمی‌آیدآدرس باید HTTPS باشد.

۵. پرسش‌های متداول

برای نصب به SSH نیاز دارم؟

خیر. همه‌ی مراحل از cPanel و مرورگر انجام می‌شود.

آیا بدون SSL کار می‌کند؟

خیر. تلگرام فقط آدرس HTTPS را می‌پذیرد. SSL را در cPanel با Let's Encrypt فعال کنید.
