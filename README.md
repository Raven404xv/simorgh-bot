## 🚀 نصب کامل روی هاست cPanel

نصب در شش مرحله انجام می‌شود. زمان تقریبی: ۱۵ تا ۲۰ دقیقه.

### مرحله ۱ — ساخت دیتابیس

1. وارد cPanel شوید و بخش **MySQL® Databases** را باز کنید.
2. یک دیتابیس بسازید، مثلاً `SimorghBot`. نام کامل آن معمولاً به شکل `cpuser_SimorghBot` است؛ همین نام کامل را یادداشت کنید.
3. یک کاربر دیتابیس با **رمز قوی** بسازید و نام کامل آن را یادداشت کنید.
4. کاربر را به دیتابیس اضافه کنید و گزینه‌ی **ALL PRIVILEGES** را فعال کنید.

### مرحله ۲ — ساخت ربات و توکن

1. در تلگرام به **[@BotFather](https://t.me/BotFather)** بروید و دستور `/newbot` را بفرستید.
2. نام و یوزرنیم ربات را انتخاب کنید و **توکن** را کپی کنید.
3. شناسه‌ی عددی خودتان را از **[@userinfobot](https://t.me/userinfobot)** بگیرید. این شناسه، ادمین اصلی ربات می‌شود.

> 🔐 توکن را هرگز در گروه، کانال یا برای دیگران نفرستید.

### مرحله ۳ — دریافت کد با Git

1. در cPanel بخش **Git™ Version Control** را باز کنید و روی **Create** بزنید.
2. آدرس مخزن را وارد کنید:
   ```
   https://github.com/Raven404xv/simorgh-bot.git
   ```
3. مسیر را `public_html/SimorghBot` بگذارید. پوشه‌ی مقصد باید خالی باشد.
4. روی **Create** بزنید تا کد ربات دریافت شود.

> 💡 اگر Git در cPanel شما نبود، می‌توانید از **File Manager** فایل ZIP مخزن را دانلود، در `public_html/SimorghBot` استخراج کنید و ادامه دهید.

### مرحله ۴ — اجرای نصب‌کننده

مرورگر را باز کنید و آدرس زیر را وارد کنید (دامنه‌ی خودتان را جایگزین کنید):

```
https://yourdomain.com/SimorghBot/install.php
```

فرم نصب را این‌طور کامل کنید:

| فیلد | مقدار |
|---|---|
| توکن ربات | توکنی که از BotFather گرفتید |
| شناسه‌ی ادمین | شناسه‌ی عددی خودتان |
| نام فروشگاه | هر نامی که می‌خواهید در ربات دیده شود |
| دیتابیس | نام کامل دیتابیس، نام کاربر و رمز را از مرحله ۱ وارد کنید |

با زدن دکمه‌ی نصب، این کارها انجام می‌شود:
- توکن با تلگرام بررسی می‌شود
- جدول‌های دیتابیس ساخته می‌شوند
- فایل `config.php` با دسترسی خصوصی ساخته می‌شود
- آدرس Webhook در تلگرام ثبت می‌شود

### مرحله ۵ — تست

1. در تلگرام به ربات بروید و `/start` بفرستید.
2. با حساب ادمین، از دکمه‌ی **⚙️ پنل مدیریت** شماره کارت، نام صاحب کارت و محصولات را ثبت کنید.
3. با یک حساب دیگر یک شارژ کیف پول و یک خرید آزمایشی انجام دهید.
4. صفحه‌ی `https://yourdomain.com/SimorghBot/selftest.php` را باز کنید. همه‌ی ردیف‌ها باید ✅ باشند.

### مرحله ۶ — امنیت پس از نصب

- فایل `install.php` بعد از نصب قفل می‌شود، با این حال آن را از File Manager حذف کنید.
- وقتی همه‌چیز را تأیید کردید، `selftest.php` را هم حذف کنید.
- فایل `config.php` را هرگز برای کسی نفرستید؛ شامل توکن و رمز دیتابیس است.

## ♻️ به‌روزرسانی

**اگر با Git نصب کرده‌اید:**
- در **Git™ Version Control** روی مخزن نصب شده **Update from Remote** را بزنید.

**اگر با ZIP نصب کرده‌اید:**
1. پوشه‌ی `src/` و فایل‌های `*.php` جدید را جایگزین کنید.
2. فایل‌های `config.php` و `installed.lock` را **دست نزنید**. تنظیمات شما حفظ می‌شود.
3. اگر جدول جدیدی لازم باشد، با `install_schema` ساخته می‌شود و داده‌های قبلی پاک نمی‌شوند.

---

## 🔒 امنیت

- فایل‌های `config.php`، `installed.lock` و پوشه‌ی `storage/` از دسترسی عمومی مسدود هستند.
- پوشه‌ی `src/` از مرورگر قابل دسترسی نیست.
- رسیدهای پرداخت فقط توسط مدیر دیده می‌شوند.
- اعتبار مینی‌اپ با امضای رسمی تلگرام بررسی می‌شود.

## 🧰 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| صفحه‌ی نصب خطای ۵۰۰ می‌دهد | نسخه‌ی PHP را ۸.۰ یا جدیدتر کنید و افزونه‌ی `pdo_mysql` را فعال کنید |
| «اتصال به دیتابیس ناموفق» | نام کامل دیتابیس (با پیشوند cPanel) و نام کاربر را دوباره بررسی کنید |

| دکمه‌ی مینی‌اپ نمی‌آید | آدرس باید HTTPS باشد و SSL دامنه فعال باشد |

| مینی‌اپ «نشست منقضی» می‌دهد | مینی‌اپ را ببندید و دوباره از داخل ربات باز کنید |
| آپلود رسید خطا می‌دهد | فقط عکس تا ۲ مگابایت مجاز است؛ مقدار `upload_max_filesize` هاست را بررسی کنید |

## 📢 ارسال همگانی

ارسال همگانی با تأخیر کوتاه بین پیام‌ها انجام می‌شود (حدود ۲۵ پیام در ثانیه). اگر تعداد کاربران بسیار زیاد باشد و هاست زمان اجرای اسکریپت را محدود کند، ارسال ممکن است کامل نشود. در این حالت باید صف ارسال با Cron راه‌اندازی شود.
