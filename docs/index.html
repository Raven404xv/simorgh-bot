برای هاست اشتراکی با cPanel. دیتابیس را خودتان می‌سازید و نصب‌کننده‌ی تحت وب را اجرا می‌کنید. For shared hosting with cPanel. You create the database yourself, then run the web installer. Для общего хостинга с cPanel. Базу данных создаёте сами, затем запускаете веб-установщик.

Git / ZIP → install.php → test

🖥️ نصب روی سرور (VPS) Install on a server (VPS) Установка на сервер (VPS)

برای سرور مجازی با دسترسی root. یک دستور همه‌چیز را نصب می‌کند و منوی مدیریت simorgh را می‌سازد. For a VPS with root access. One command installs everything and creates the simorgh management menu. Для VPS с правами root. Одна команда устанавливает всё и создаёт меню управления simorgh.

One command → menu → automatic setup
توکن ربات را محرمانه نگه دارید. Keep your bot token private. Храните токен бота в тайне.
توکن را هرگز در گروه، کانال یا پیام عمومی نفرستید. اگر لو رفت، با دستور /revoke در BotFather آن را عوض کنید. Never post your token in a group, channel or public message. If it leaks, revoke it with /revoke in BotFather. Никогда не публикуйте токен в группе, канале или открытом сообщении. Если он утёк, отзовите его командой /revoke в BotFather.

نصب روی هاست cPanel Installation on cPanel hosting Установка на хостинг cPanel

1 ساخت دیتابیسCreate the databaseСоздание базы данных

  1. در cPanel بخش MySQL® Databases را باز کنید، یک دیتابیس و یک کاربر با رمز قوی بسازید و کاربر را با دسترسی ALL PRIVILEGES به دیتابیس اضافه کنید. In cPanel, open MySQL® Databases, create a database and a user with a strong password, then add the user with ALL PRIVILEGES. В cPanel откройте MySQL® Databases, создайте базу данных и пользователя с надёжным паролем, затем добавьте пользователя с правами ALL PRIVILEGES.
  2. نام کامل دیتابیس و کاربر را با پیشوند حساب یادداشت کنید، مثلاً cpuser_SimorghBot. Note the full database and user names, including the account prefix, for example cpuser_SimorghBot. Запишите полные имена базы данных и пользователя с префиксом аккаунта, например cpuser_SimorghBot.

2 ساخت رباتCreate the botСоздание бота

  1. در تلگرام به @BotFather بروید و دستور /newbot را بفرستید؛ توکن را کپی کنید. In Telegram, open @BotFather, send /newbot and copy the token. В Telegram откройте @BotFather, отправьте /newbot и скопируйте токен.
  2. شناسه‌ی عددی خود را از @userinfobot بگیرید. Get your numeric ID from @userinfobot. Получите свой числовой ID в @userinfobot.

3 دریافت فایل‌هاGet the filesПолучение файлов

در cPanel بخش Git™ Version Control را باز کنید و آدرس زیر را با مسیر public_html/SimorghBot وارد کنید. یا فایل ZIP را از GitHub دانلود کنید، در File Manager آپلود و استخراج کنید. In cPanel, open Git™ Version Control and clone the repository into public_html/SimorghBot. Or download the ZIP from GitHub, upload it in File Manager and extract it. В cPanel откройте Git™ Version Control и клонируйте репозиторий в public_html/SimorghBot. Или скачайте ZIP с GitHub, загрузите его в File Manager и распакуйте. 

https://github.com/Raven404xv/simorgh-bot.git

4 اجرای نصب‌کنندهRun the installerЗапуск установщика

این آدرس را باز کنید و فرم را کامل کنید: توکن، شناسه‌ی ادمین، نام فروشگاه و اطلاعات دیتابیس. Open this address and complete the form: token, admin ID, store name and database details. Откройте этот адрес и заполните форму: токен, ID администратора, название магазина и данные базы данных. 

https://yourdomain.com/SimorghBot/install.php

5 تست و امنیتTest and secureПроверка и безопасность

  1. در تلگرام /start بفرستید و صفحه‌ی بررسی را باز کنید. Send /start in Telegram and open the check page. Отправьте /start в Telegram и откройте страницу проверки.
  2. بعد از اطمینان، فایل‌های install.php و selftest.php را حذف کنید. When everything works, delete install.php and selftest.php. Когда всё работает, удалите install.php и selftest.php. 
https://yourdomain.com/SimorghBot/selftest.php

نصب روی سرور (VPS) Installation on a server (VPS) Установка на сервер (VPS)

پیش‌نیازها: Ubuntu 22.04 یا جدیدتر، یا Debian 12 یا جدیدتر؛ دسترسی root؛ پورت ۴۴۳ یا ۸۴۴۳ آزاد؛ دامنه‌ی اختیاری با رکورد A به IP سرور. Requirements: Ubuntu 22.04+ or Debian 12+; root access; port 443 or 8443 free; optional domain with an A record pointing to the server IP. Требования: Ubuntu 22.04+ или Debian 12+; доступ root; свободный порт 443 или 8443; необязательный домен с записью A на IP сервера.

1 اجرای دستور نصبRun the install commandЗапуск команды установки

با SSH به سرور وصل شوید و این دستور را اجرا کنید. منوی مدیریت باز می‌شود و دستور simorgh ساخته می‌شود. Connect to the server over SSH and run this command. The management menu opens and the simorgh command is created. Подключитесь к серверу по SSH и выполните команду. Откроется меню управления, и появится команда simorgh. 

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/Raven404xv/simorgh-bot/main/simorgh.sh)"

از این به بعد فقط این را تایپ کنید: From now on, just type: Дальше достаточно ввести: 

simorgh

2 منوی مدیریتThe management menuМеню управления

گزینهOptionПункт کاربردActionДействие
1 نصب رباتInstall the botУстановка бота
2 حذف کامل ربات (با تأیید)Remove the bot completely (with confirmation)Полное удаление бота (с подтверждением)
3 به‌روزرسانی با پشتیبان‌گیری از تنظیماتUpdate, with a backup of your settingsОбновление с резервной копией настроек
4 لاگ‌های زنده (Ctrl+C برای بازگشت)Live logs (Ctrl+C to return)Логи в реальном времени (Ctrl+C — назад)
5 رفع اتصال تلگرام و نمایش وضعیت وب‌هوکFix the Telegram connection and show webhook statusИсправление подключения к Telegram и статус вебхука
6 خروجExitВыход

3 نصب از منوInstall from the menuУстановка из меню

  1. گزینه‌ی 1 را بزنید. اگر دامنه دارید y و نام دامنه و ایمیل را وارد کنید؛ اگر ندارید n بزنید تا روی IP سرور نصب شود. Choose 1. With a domain, answer y and enter the domain and email. Without one, answer n to install on the server IP. Выберите 1. Если есть домен, ответьте y и введите домен и e-mail; если нет — n, и установка пойдёт на IP сервера.
  2. پورت و گواهی به‌صورت خودکار انتخاب می‌شوند. Enter را بزنید تا خلاصه‌ی نصب تأیید و نصب شروع شود. The port and certificate are chosen automatically. Press Enter to confirm the summary and start. Порт и сертификат выбираются автоматически. Нажмите Enter, чтобы подтвердить сводку и начать установку.
  3. پس از نصب، آدرس صفحه‌ی نصب نمایش داده می‌شود. اطلاعات دیتابیس را با sudo cat /root/simorgh-credentials.txt ببینید و فرم را کامل کنید. When it finishes, the setup address is shown. Get the database details with sudo cat /root/simorgh-credentials.txt and complete the form. По завершении показывается адрес страницы установки. Данные базы смотрите командой sudo cat /root/simorgh-credentials.txt и заполните форму.
اگر از IP استفاده کردید، مرورگر هشدار گواهی می‌دهد. این طبیعی است: روی Advanced و سپس Proceed بزنید. With an IP address the browser shows a certificate warning. This is expected: click Advanced, then Proceed. При использовании IP браузер покажет предупреждение о сертификате. Это нормально: нажмите Advanced, затем Proceed.

4 اگر ربات جواب ندادIf the bot does not replyЕсли бот не отвечает

منوی simorgh را باز کنید و گزینه‌ی 5 را بزنید. سپس دوباره /start بفرستید. Run simorgh, choose 5, then send /start again. Запустите simorgh, выберите 5, затем снова отправьте /start.

خیر. بدون دامنه ربات روی IP سرور با گواهی خودامضا نصب می‌شود. با دامنه، گواهی معتبر گرفته می‌شود. No. Without a domain the bot runs on the server IP with a self-signed certificate. With a domain, a trusted certificate is issued. Нет. Без домена бот работает на IP сервера с самоподписанным сертификатом. С доменом выдаётся доверенный сертификат.

خیر. نصب‌کننده‌ی سرور پایگاه داده و کاربر اختصاصی را خودکار می‌سازد. No. The server installer creates the database and a dedicated user automatically. Нет. Установщик для сервера автоматически создаёт базу данных и отдельного пользователя.
