شروع سریع

اگر با cPanel آشنا هستید، این خلاصه برای شما کافی است:

  1. دیتابیس و کاربر MySQL بسازید و کاربر را با ALL PRIVILEGES به دیتابیس اضافه کنید.
  2. توکن ربات را از BotFather و شناسه‌ی عددی خود را از userinfobot بگیرید.
  3. کد را در public_html/SimorghBot قرار دهید (Git یا ZIP).
  4. صفحه‌ی install.php را باز کرده و فرم را کامل کنید.
  5. در تلگرام /start بفرستید و از selftest.php مطمئن شوید.

نصب قدم‌به‌قدم روی هاست

برای اینکه هیچ مرحله‌ای جا نماند، هر مرحله را به ترتیب انجام دهید.

۱

ساخت دیتابیس MySQL

  1. وارد cPanel شوید و بخش MySQL® Databases را باز کنید.
  2. در کادر Create New Database نام دلخواه بنویسید، مثلاً SimorghBot، و بزنید.
  3. نام کامل دیتابیس را یادداشت کنید. cPanel پیشوند حساب را به آن اضافه می‌کند، مثلاً cpuser_SimorghBot.
  4. در بخش MySQL Users یک کاربر با رمز قوی بسازید و نام کامل کاربر (با پیشوند) را یادداشت کنید.
  5. در بخش Add User To Database کاربر را به دیتابیس اضافه کنید و گزینه‌ی ALL PRIVILEGES را تیک بزنید.
نکته: رمز دیتابیس را جایی امن نگه دارید. بعداً در صفحه‌ی نصب به آن نیاز دارید.
۲

ساخت ربات و گرفتن توکن

  1. در تلگرام به @BotFather بروید و دستور /newbot را بفرستید.
  2. نام و یوزرنیم ربات را انتخاب کنید. یوزرنیم باید به bot ختم شود.
  3. توکنی را که BotFather می‌دهد کپی کنید. شکل آن شبیه 123456:ABC... است.
  4. شناسه‌ی عددی خود را از @userinfobot بگیرید. این شناسه، ادمین اصلی ربات می‌شود.
امنیت توکن: توکن را هرگز در گروه، کانال یا پیام عمومی نفرستید. اگر لو رفت، با /revoke در BotFather آن را عوض کنید.
۳

دریافت فایل‌های ربات

یکی از دو روش زیر را انتخاب کنید. روش Git ساده‌تر و برای به‌روزرسانی مناسب‌تر است.

روش الف: Git در cPanel

  1. در cPanel بخش Git™ Version Control را باز کنید و روی Create بزنید.
  2. آدرس مخزن را وارد کنید:
https://github.com/Raven404xv/simorgh-bot.git
  1. در بخش مسیر، public_html/SimorghBot را بگذارید. پوشه‌ی مقصد باید خالی باشد.
  2. روی Create بزنید تا فایل‌ها دریافت شوند.

روش ب: فایل ZIP از طریق File Manager

  1. در صفحه‌ی مخزن GitHub روی Code و سپس Download ZIP بزنید.
  2. در File Manager به پوشه‌ی public_html بروید و فایل را آپلود کنید.
  3. روی فایل راست‌کلیک کنید و Extract بزنید. نام پوشه‌ی استخراج‌شده را به SimorghBot تغییر دهید.
دقت کنید: فایل‌های config.php و installed.lock در مخزن نیستند و خودشان ساخته می‌شوند. آن‌ها را دستی نسازید.
۴

اجرای نصب‌کننده

مرورگر را باز کنید و آدرس زیر را وارد کنید. دامنه‌ی خودتان را جایگزین کنید:

https://yourdomain.com/SimorghBot/install.php

فرم را این‌طور کامل کنید:

فیلدچه چیزی وارد شود
توکن رباتتوکنی که از BotFather گرفتید
شناسه‌ی ادمینشناسه‌ی عددی خودتان از userinfobot
نام فروشگاهنامی که در ربات دیده می‌شود
میزبان دیتابیسمعمولاً localhost
نام دیتابیسنام کامل همراه با پیشوند، مثل cpuser_SimorghBot
کاربر دیتابیسنام کامل کاربر همراه با پیشوند
رمز دیتابیسهمان رمزی که برای کاربر ساختید

بعد از زدن دکمه‌ی نصب، این کارها خودکار انجام می‌شود:

  • توکن با تلگرام بررسی می‌شود.
  • جدول‌های دیتابیس ساخته می‌شوند.
  • فایل config.php با دسترسی خصوصی ساخته می‌شود.
  • آدرس وب‌هوک در تلگرام ثبت می‌شود.
نکته: اگر خطای اتصال به دیتابیس دیدید، نام کامل دیتابیس و کاربر را با پیشوند cPanel دوباره بررسی کنید.
۵

تست ربات

  1. در تلگرام به ربات بروید و /start بفرستید.
  2. با حساب ادمین، از دکمه‌ی ⚙️ پنل مدیریت شماره کارت، نام صاحب کارت و محصولات را ثبت کنید.
  3. با یک حساب دیگر، یک شارژ کیف پول و یک خرید آزمایشی انجام دهید.
  4. صفحه‌ی selftest.php را باز کنید:
https://yourdomain.com/SimorghBot/selftest.php

همه‌ی ردیف‌ها باید ✅ باشند. اگر ردیفی خطا داشت، آن را در بخش عیب‌یابی پیدا کنید.

۶

امنیت بعد از نصب

  • فایل install.php بعد از نصب قفل می‌شود، با این حال آن را از File Manager حذف کنید.
  • وقتی همه‌چیز را تأیید کردید، selftest.php را هم حذف کنید.
  • فایل config.php را هرگز برای کسی نفرستید؛ شامل توکن و رمز دیتابیس است.
مهم: بدون حذف install.php، هر کسی که آدرس آن را داشته باشد می‌تواند تنظیمات را تغییر دهد.

به‌روزرسانی

اگر با Git نصب کرده‌اید

  1. در Git™ Version Control روی مخزن نصب‌شده بزنید.
  2. گزینه‌ی Update from Remote را انتخاب کنید.

اگر با ZIP نصب کرده‌اید

  1. پوشه‌ی src/ و فایل‌های *.php جدید را جایگزین کنید.
  2. فایل‌های config.php و installed.lock را دست نزنید؛ تنظیمات شما حفظ می‌شود.
  3. اگر جدول جدیدی لازم باشد، با install_schema ساخته می‌شود و داده‌های قبلی پاک نمی‌شوند.

عیب‌یابی

مشکلراه‌حل
صفحه‌ی نصب خطای ۵۰۰ می‌دهدنسخه‌ی PHP را ۸.۰ یا جدیدتر کنید و افزونه‌ی pdo_mysql را فعال کنید.
اتصال به دیتابیس ناموفق استنام کامل دیتابیس و کاربر (با پیشوند cPanel) و رمز را بررسی کنید.
ربات به /start جواب نمی‌دهدselftest.php را باز کنید و ردیف «خطای آخر Webhook» را بخوانید.
دکمه‌ی مینی‌اپ نمی‌آیدآدرس باید HTTPS باشد و SSL دامنه فعال باشد.
گزارش‌ها در گروه ثبت نمی‌شوندگروه باید سوپرگروه با Topics باشد و ربات دسترسی مدیریت تاپیک داشته باشد.
مینی‌اپ «نشست منقضی» می‌دهدمینی‌اپ را ببندید و دوباره از داخل ربات باز کنید.
آپلود رسید خطا می‌دهدفقط عکس تا ۲ مگابایت مجاز است؛ مقدار upload_max_filesize هاست را بررسی کنید.

سؤالات متداول

آیا برای نصب به SSH نیاز دارم؟

خیر. تمام مراحل از طریق cPanel و مرورگر انجام می‌شود.

آیا می‌توانم ربات را روی دامنه‌ای بدون SSL نصب کنم؟

تلگرام فقط آدرس HTTPS را می‌پذیرد، پس SSL لازم است. در cPanel بخش SSL/TLS Status یا Let's Encrypt را فعال کنید.

ارسال همگانی کامل انجام می‌شود؟

ارسال با تأخیر کوتاه بین پیام‌ها انجام می‌شود (حدود ۲۵ پیام در ثانیه). اگر تعداد کاربران خیلی زیاد باشد و هاست زمان اجرا را محدود کند، ارسال ممکن است کامل نشود. در این حالت باید صف ارسال با Cron راه‌اندازی شود.

اطلاعات ادمین را از کجا تغییر دهم؟

از داخل ربات و پنل مدیریت. تغییر مستقیم config.php توصیه نمی‌شود.
